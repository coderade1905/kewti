Kewti supports AI coding assistants directly through the CLI. By installing the Kewti AI skill into your repository, your AI assistant (Antigravity, Cursor, GitHub Copilot, Claude, OpenAI Codex) learns how to explore available components, inspect official documentation, and install localized Ethiopian UI components, fonts, and logos.

---

## Quick Start: Install AI Skill

Run the `skill` command directly in your project root:

```bash
# Auto-configure for all supported AI agents
npx kewti-cli skill
```

You can also use the install shortcut:

```bash
# Shortcut via add command
npx kewti-cli add skill
```

### Target a Specific AI Agent

Pass the agent name as an argument or using the `--agent` option:

```bash
# For Antigravity (targets: antigravity, agy)
npx kewti-cli skill antigravity

# For Cursor AI (targets: cursor)
npx kewti-cli skill cursor

# For GitHub Copilot (targets: copilot, github)
npx kewti-cli skill copilot

# For Claude & Universal Agents (targets: claude, agents)
npx kewti-cli skill claude

# For OpenAI Codex / Codex CLI (targets: codex, openai)
npx kewti-cli skill codex

# Using the --agent flag
npx kewti-cli skill --agent cursor
```

### Preview Changes (`--dry-run`)

Preview the exact files that will be created without modifying your project:

```bash
npx kewti-cli skill --dry-run
# or
npx kewti-cli add skill --dry-run
```

## Supported AI Environments & Generated Files

When you install skills, the CLI writes configuration files based on the chosen agent target:

### 1. Antigravity (`antigravity`, `agy`)
Creates:
- `.agents/skills/kewti/SKILL.md` — Antigravity Kewti skill definition.

### 2. Cursor (`cursor`)
Creates:
- `.cursorrules` — Project-level Cursor rules.
- `.cursor/rules/kewti.mdc` — Cursor rules directory configuration.

### 3. GitHub Copilot (`copilot`, `github`)
Creates:
- `.github/copilot-instructions.md` — GitHub Copilot repository instructions.

### 4. Claude & Universal Agents (`claude`, `agents`)
Creates:
- `CLAUDE.md` — Claude project guide.
- `AGENTS.md` — Universal agent guidelines.

### 5. OpenAI Codex (`codex`, `openai`)
Creates:
- `CODEX.md` — OpenAI Codex / Codex CLI guidelines.

*(Running `npx kewti-cli skill` or `npx kewti-cli skill all` generates all of the files above.)*

## How AI Agents Use `kewti-cli`

Once the skill is installed, AI agents interact with Kewti through the following CLI commands:

### 1. Discover Components, Fonts, and Logos (`list`)

Agents list available registry items in human-readable or machine-readable format:

```bash
# Human-readable overview
npx kewti-cli list

# JSON output for AI consumption
npx kewti-cli list --json

# Filter by registry type ('components', 'fonts', or 'logos')
npx kewti-cli list --type components --json
npx kewti-cli list --type fonts --json
npx kewti-cli list --type logos --json
```

The CLI registry covers components and assets such as:
- **`calendar`**: Complete Ethiopian calendar & date picker with 13 months, Kenat date arithmetic, holiday badges, and animated month artwork.
- **`time`**: Ethiopian 12-hour cyclical time picker (ጠዋት, ከሰዓት, ምሽት, ሌሊት) with standard 24-hour time conversion.
- **`input`**: Phonetic Amharic input with real-time Latin-to-Ge'ez transliteration, voice dictation, Kebele/TIN formatting, and fuzzy spellchecking.
- **`numerals`**: Ge'ez numeral converter and spelled-out Amharic word translator with Birr and Santim currency support.
- **`location-selector`**: Ethiopian administrative location selector with cascading Region, Zone/Subcity, and Woreda dropdowns.
- **`select`**: Searchable dropdown select component with support for remote API data sources and icons.
- **`spell`**: Fuzzy dictionary spellchecker for Ge'ez/Amharic words with autocorrection dropdown.
- **`gursha`**: Ethiopian tipping and "Buy Me a Coffee" button integrated with Gursha Plus profiles.
- **`fonts`**: Ethiopic font preview wrappers and audio pronunciation component using Web Speech API.
- **`logo`**: Vector brand logo component for Ethiopian commercial banks, telecom, government agencies, and tech brands.

### 2. Inspect Details and Usage Snippets (`info`)

Agents fetch component descriptions, npm dependencies, registry dependencies, target file paths, and ready-to-use code snippets:

```bash
# Inspect component snippet and dependency details
npx kewti-cli info calendar
npx kewti-cli info time

# Inspect info as JSON for machine parsing
npx kewti-cli info calendar --json

# Inspect skill configuration info
npx kewti-cli info skill --json
```

### 3. Read Documentation from the Terminal (`docs`)

Agents can fetch full MDX documentation locally from the workspace or remotely from the Kewti docs server:

```bash
# View topic overview
npx kewti-cli docs
npx kewti-cli docs --json

# Fetch documentation for a specific component
npx kewti-cli docs calendar
npx kewti-cli docs time
npx kewti-cli docs input --json
```

### 4. Install Components & Assets (`add` / `install`)

Agents can install components, fonts, or logos into the project:

```bash
# Install UI components
npx kewti-cli add calendar
npx kewti-cli add time input

# Install with preview
npx kewti-cli add calendar --dry-run

# Install font packages
npx kewti-cli add font <font-name>
# or
npx kewti-cli font <font-name>

# Install brand logo assets into src/kewti/logos/
npx kewti-cli add logos <logo-name>
# or
npx kewti-cli logo <logo-name>
```

## Machine-Readable AI Endpoints

The CLI communicates with the following endpoints for documentation and registry indexing:

- **Docs Base URL:** `https://kewti-docs.vercel.app` (configurable via `KEWTI_DOCS_URL`)
- **Docs Index:** `https://kewti-docs.vercel.app/docs`
- **Agent Context (`llms.txt`):** `https://kewti-docs.vercel.app/llms.txt`
- **Full Agent Context (`llms-full.txt`):** `https://kewti-docs.vercel.app/llms-full.txt`
- **Component Markdown Content:** `https://kewti-docs.vercel.app/llms.mdx/docs/components/<component>/content.md`
- **Remote Registry Base:** `https://kewti-registry.vercel.app`
