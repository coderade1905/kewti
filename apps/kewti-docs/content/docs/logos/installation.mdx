## Installation

```bash
npx kewti-cli add logo
```

## Usage

```tsx
import { KewtiLogo } from "@/kewti/ui"
import type { KewtiLogoName } from "@/kewti/ui"
```

---

## Basic Example

`registryUrl` is required on every instance to locate and load the logo assets.

```tsx
<KewtiLogo
  name="commercial_bank_of_ethiopia"
  registryUrl="https://kewti-registry.vercel.app"
/>
```

---

## Size Presets & Custom Dimensions

Supports standardized size presets (`xs`, `sm`, `md`, `lg`, `xl`) or direct continuous pixel and CSS values (`number`, `"3rem"`, `"72px"`).

```tsx
const REGISTRY_URL = "https://kewti-registry.vercel.app"

<div className="flex items-center gap-4">
  <KewtiLogo name="ethio_telecom" registryUrl={REGISTRY_URL} size="sm" />       {/* 24px */}
  <KewtiLogo name="ethio_telecom" registryUrl={REGISTRY_URL} size="md" />       {/* 40px */}
  <KewtiLogo name="ethio_telecom" registryUrl={REGISTRY_URL} size="lg" />       {/* 56px */}
  <KewtiLogo name="ethio_telecom" registryUrl={REGISTRY_URL} size="xl" />       {/* 80px */}
  <KewtiLogo name="ethio_telecom" registryUrl={REGISTRY_URL} size={96} />        {/* 96px */}
  <KewtiLogo name="ethio_telecom" registryUrl={REGISTRY_URL} size="4.5rem" />   {/* Custom CSS */}
</div>
```

---

## Format Selection

Toggle between vector SVGs (`"svg"`) or raster PNGs (`"png"`).

```tsx
const REGISTRY_URL = "https://kewti-registry.vercel.app"

{/* Vector SVG (default) */}
<KewtiLogo name="chapa" registryUrl={REGISTRY_URL} format="svg" />

{/* Raster PNG */}
<KewtiLogo name="chapa" registryUrl={REGISTRY_URL} format="png" />
```

---

## Custom Fallback UI

Provide a customized React fallback component when network requests fail or an unindexed logo is requested.

```tsx
<KewtiLogo
  name="unknown_brand"
  registryUrl="https://kewti-registry.vercel.app"
  fallback={
    <div className="h-10 px-3 bg-muted rounded-md flex items-center text-xs text-muted-foreground border">
      Logo Unavailable
    </div>
  }
/>
```

## Features

* **Explicit Registry Routing:** Requires a `registryUrl` prop, guaranteeing transparent asset loading from your designated CDN, cloud storage, or local server.
* **Comprehensive Ethiopian Directory:** Over 60 indexed logos covering commercial banks, telecom, government agencies, universities, and tech startups.
* **Dual Format Asset Delivery:** Seamlessly loads scalable `.svg` or high-resolution `.png` files directly from the specified registry host.
* **Flexible Sizing Engine:** Built-in size ladder (`xs: 16px`, `sm: 24px`, `md: 40px`, `lg: 56px`, `xl: 80px`) alongside arbitrary numeric pixel values and CSS dimension strings.
* **Accessible by Default:** Automatically formats `snake_case` keys into human-readable Title Case strings for `alt` attributes (e.g. `bank_of_abyssinia` → `"Bank Of Abyssinia logo"`).
* **Zero Layout Shift:** Explicit dimensions are applied to maintain stable document layouts while images load.

## Props

### `KewtiLogo` Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `KewtiLogoName` | — | **Required.** The registered logo identifier key. |
| `registryUrl` | `string` | — | **Required.** Base URL where public registry assets are hosted. |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| number \| string` | `"md"` | Preset (`"xs"`, `"sm"`, `"md"`, `"lg"`, `"xl"`), pixel number, or CSS size string. |
| `format` | `"svg" \| "png"` | `"svg"` | The file extension and format to fetch from the registry. |
| `fallback` | `React.ReactNode` | — | Optional custom element rendered when the logo fails to load. |
| `alt` | `string` | `"{Title} logo"` | Accessible alternate text for screen readers. Auto-generated if omitted. |
| `className` | `string` | `""` | Optional CSS class names applied to the `<img>` element. |
| `style` | `React.CSSProperties` | — | Direct inline styles applied to the image element. |
